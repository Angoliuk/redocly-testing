# Realm documentation

Welcome to the documentation for the Realm service API.
This API provides access to the Realm catalog, including entities, relations, and health check operations.

## Overview

The Realm API allows you to manage catalog entities and their relationships.
It also includes a CORS proxy and BFF (Backend for Frontend) endpoints for catalog entities.

- Catalog Entities: Manage and retrieve information about entities in the catalog.
- Entity Relations: Define and query relationships between catalog entities.
- BFF Endpoints: Optimized endpoints for frontend consumption.
- Health Checks: Monitor the service status.
