# redocly-testing

This repository contains Redocly documentation and API definitions for the Realm service.

## Project structure

The project follows a standard Redocly structure.

- `docs/` contains documentation pages in Markdown format.
- `openapi.yaml` defines the Realm API using the OpenAPI Specification.

## Documentation access

Access the documentation files in the `docs` directory.
Each Markdown file represents a page in the documentation site.

## Contribution guide

To contribute to the documentation, edit or add Markdown files in the `docs` directory.
Update the `openapi.yaml` file to modify the API definitions.
