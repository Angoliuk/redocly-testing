# Redocly Cafe API

The Redocly Cafe API provides a comprehensive set of tools for cafe operators to manage their daily business operations.
This API is designed specifically for operators to handle menus, process orders, and monitor revenue performance.
It is not intended for use by cafe customers.

## Key capabilities

- **Menu management**: Create, update, and organize your cafe products, including beverages and desserts.
- **Order management**: Manage the full lifecycle of customer orders from creation to completion.
- **Revenue insights**: Access detailed statistics and reports on your cafe financial performance.

## Get started

To begin using the Redocly Cafe API, follow these steps:

1.  **Understand the API**: Review the core concepts and capabilities described in this documentation.
2.  **Authentication**: Register your client and obtain authorization tokens to interact with the endpoints.
3.  **Explore endpoints**: Visit the API reference sections to see detailed information on available paths and data models.

Whether you automate your order flow or build a custom dashboard for revenue monitoring, the Redocly Cafe API provides the endpoints you need to succeed.
