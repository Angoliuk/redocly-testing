# Welcome to our API documentation

This portal provides comprehensive documentation for our APIs, including OpenAPI, AsyncAPI, and GraphQL formats.

## API mock server

Our documentation portal includes an integrated API mock server.
This feature allows developers to prototype and test API calls without a live backend.

### Benefits

- Prototyping: Start developing against our APIs before the backend implementation is complete.
- Testing: Easily test your client applications with consistent mock responses.
- Speed: Reduce dependency on live environments during the early stages of development.

### How to use

You can find the mock server URL in the "Try It" section of any API documentation page.
Simply select the mock server option from the server dropdown list to use the mock base URL for your requests.
